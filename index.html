2x2 Rubik's Cube Solving Robot

Built with LEGO EV3 for our engineering class project

🔧 Overview

This project represents an innovative fusion of robotics, computer vision, and puzzle-solving algorithms. Our team developed an autonomous robot capable of solving a 2x2 Rubik's Cube using LEGO EV3 components and motors. The project demonstrates practical applications of engineering principles, programming logic, and mechanical design.

At its core, our robot employs a sophisticated system that combines hardware and software components:

  • Hardware Integration: Custom-built gripper mechanism with precise motor control for cube manipulation, integrated color sensors for state detection, and a robust chassis design that ensures stable operation.
  • Software Architecture: Advanced algorithms for cube state recognition, solution computation using optimized solving methods, and real-time motor control for accurate cube rotations.
  • Key Features: Autonomous operation, reliable color detection, efficient solving algorithm, and precise mechanical movements.

The project's success lies in its ability to bridge theoretical concepts with practical implementation. We faced and overcame several challenges, including:

  • Designing a reliable gripping mechanism that could handle the cube without damaging it
  • Implementing accurate color detection in various lighting conditions
  • Optimizing the solving algorithm for speed and efficiency
  • Ensuring precise motor control for consistent cube rotations

Through this project, we've demonstrated how modern robotics can transform complex puzzle-solving into an automated process. Our robot not only showcases the practical application of engineering principles but also serves as a testament to the power of combining hardware innovation with algorithmic thinking. The successful implementation of this system opens doors for further exploration in automated puzzle-solving and educational robotics applications.

🧠 How It Works

  • For each face of the vube, the color sensor detects the color of each square and maps it to its respective position.
  • The cube state is converted into a digital representation
  • We use a massive hash table to store the cube state and its solution. Once we have the cube state, we simple look up the solution in the hash table.
  • The solution is then converted into actionable items for the robot.
  • Pybricks is then used to make the robot perform the moves in the solution.
